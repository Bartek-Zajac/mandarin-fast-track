# Mandarin Fast Track

A lightweight Mandarin learning app focused on useful Chinese: high-frequency characters, practical sentences, tone recognition, pronunciation playback, and mistake-weighted review.

## Features

- 1,000+ unique Chinese character bank
- Frequency-first core character deck with pinyin, meanings, and example words
- Practical Mandarin sentence drills
- Four-tone listening practice
- Mandarin pronunciation through the browser Speech Synthesis API
- Mistake-weighted review: cards marked **Again** return sooner
- Responsive, dependency-free HTML/CSS/JavaScript

## Run locally

Because the app has no build step, you can open `index.html` directly or serve the directory with any static HTTP server.

## Deploy on Vercel

Import this GitHub repository into Vercel. It is a static site and requires no framework preset or build command. Vercel can serve the repository root directly.

Once Git integration is enabled, pushes to the production branch can automatically create new deployments, which makes it easy to keep improving the app through GitHub.

## Roadmap

Good next improvements include persistent spaced-repetition progress, a stronger frequency-ranked dataset with full pinyin/definitions for every character, listening quizzes, sentence difficulty levels, handwriting/stroke-order practice, vocabulary decks by real-life situation, and user accounts/cloud sync.
